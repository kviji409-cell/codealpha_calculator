# CodeAlpha Task 1: Basic Calculator in C

## Description
A simple C calculator that performs addition, subtraction, multiplication, and division using a `switch` statement.

## Features
- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Handles division by zero and invalid operators

## How to Compile and Run
Using GCC:

```bash
gcc task1_calculator.c -o calculator
./calculator
```

On Windows:

```bash
gcc task1_calculator.c -o calculator.exe
calculator.exe
```

## Example
Input: `12 * 4`

Output: `Result: 48.00`
